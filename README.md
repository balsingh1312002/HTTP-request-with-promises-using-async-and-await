Fetch Users Data from API using JavaScript
📌 About the Project

This project demonstrates how to fetch user data from the JSONPlaceholder API using JavaScript with two approaches: Promises (.then() and .catch()) and Async/Await. It covers API requests, JSON parsing, and error handling.

🎯 Objectives
Fetch user data from a REST API.
Convert the response into JSON.
Display user data in the console.
Implement Promises and Async/Await.
Handle errors properly.
🔗 API Endpoint

https://jsonplaceholder.typicode.com/users

🛠️ Technologies Used
JavaScript (ES6+)
Fetch API
JSONPlaceholder API
📂 Project Structure
fetch-users-api/
├── index.js
└── README.md

🚀 How to Run
Clone this repository:
git clone <your-repository-url>

Navigate to the project folder:
cd fetch-users-api

Run the JavaScript file using Node.js:
node index.js

Check the terminal to see the fetched user data.
💡 Approaches Implemented
1. Promises

Uses .then() to process the response and .catch() to handle errors.

2. Async/Await

Uses async and await for cleaner asynchronous code, with try...catch for error handling.

📚 Learning Outcomes
Understanding HTTP requests and REST APIs.
Working with JSON data.
Learning Promises and Async/Await.
Handling errors in asynchronous JavaScript.
